# Displayed formula spacing

The space \(A\) is one-dimensional. Inline formulas keep their normal spacing.

A displayed equation follows this paragraph:

\[
E = mc^2
\]

The next paragraph should follow at the normal distance.

A second example uses double-dollar delimiters:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

The normal spacing should be consistent for every displayed formula.
