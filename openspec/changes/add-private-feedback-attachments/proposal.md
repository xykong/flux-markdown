# Change: 默认私密的反馈附件

## Why
用户已于本次对话明确批准“默认私密，主动勾选才公开；Issue只显示私密编号；维护者可取件，上传者和其他用户不可从服务下载”。原上传方案已部署，不能仅隐藏公开链接冒充权限控制。

## What Changes
- 保留默认附带文档，新增默认不勾选的“公开附件下载链接”；只影响本次报告，选择随中断草稿恢复。
- 私密收件回执不返回下载URL；服务对落盘内容校验摘要后确认，客户端不得私密下载复核。
- 私密报告只公开 `Attachment reference: FM-<opaque-id>`；标识、上传键、删除键都不具备私密读取权限。
- 维护者通过已有SSH身份认证及服务账号权限，用受控CLI导出附件并记录操作审计；不增加公共管理下载接口，不向App发维护者凭据。
- 公开附件的对象编号与下载令牌分开；服务保存不可变的共享范围，重试更换范围返回冲突，用户需删除并重新提交。
- 未关联7天过期；私密附件即使关联Issue也最长30天，公开关联附件继续保留至删除。七天备份轮换及删除说明同步公开。
- 旧公开附件按原授权保持公开，旧本地恢复记录不会被自动升级为公开选择。老二进制降级不能读取新私密记录。
