# 设计与边界
- 已有缩放、图表控件和安全渲染机制继续复用。专注面板移动原图宿主到固定覆盖层，保留 DOM、事件与局部倍率；关闭时原位归还并恢复焦点和阅读锚点，不另行渲染第二张图。
- 专注层提供独立的适应窗口与 100% 操作，保留双指和双指双击语义；普通双指滚动在专注层内部平移，不推动背景。App 的 Esc 关闭，QuickLook 保留明确关闭按钮，不冒充系统键盘可控性。
- 锚点采用元素 ID、文本摘要哈希与块序号、屏幕偏移、原始 scrollY、文档倍率；不持久化正文。存储最多 100 个文件，历史最多 100 个条目。明确目标跳转优先于自动恢复。
- 目录/脚注同文档跳转可恢复；跨文件链接由原生文档控制器打开并维护共享历史，前进后退不生成新历史分支。普通滚动不产生历史条目。
- 原生桥只接受主 frame、bundled renderer origin、当前 generation，验证类型、预算与操作白名单；图表导出只接受安全 SVG / PNG。导出先由用户选择位置；取消不算失败。
- 图表复制/导出错误复用已有原生 ErrorFeedback；成功仅在剪贴板/原子文件写入完成后反馈。QuickLook 的文件导出转到 App（明确说明），不扩大扩展的沙箱写权限。
- 端到端分层：真实 WebKit 几何与交互、原生桥剪贴板/文件读回、跨文件原生打开/历史、真实 SwiftUI 菜单、安装版本与资源摘要；Intel 同 bundle 验证。触控板主观体验不以合成事件替代。
