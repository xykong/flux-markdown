## Decisions
Use Bash plus macOS JavaScript for Automation, requiring no Python, Node or developer tools on the reporter's machine. Keep the distributable collector in one file. Commands and streaming have time/output limits; stop only task-owned children. Preserve raw evidence locally in owner-only storage, export only exact-schema allowlisted fields.

Run a dedicated UUID self-test and reveal a second UUID fixture in Finder; capture starts first. Native stage events apply only to dedicated fixture filenames. The collector correlates both UUID and extension executable identity, retaining alternate-copy observations separately. Self-test success is not Finder success, a process existing is not invocation, and missing logs are not proof of no execution. The user supplies the visible Finder outcome separately.

The tool never repairs registrations, clears caches, changes associations, installs software, uploads data or posts issues. Ctrl+C produces partial results. Failed collection/packaging retains files and offers explicit sharing/retry paths. Native error UI remains ErrorIncident/ErrorFeedback.

## Verification
Adversarial/private log fixtures, interleaved UUIDs, wrong copies/builds, missing stages, explicit errors, legacy records, malformed/truncated input, command failure, timeout and interruption. Real local positive probe plus wrong-content negative scenario exercise installed stage events; actual disabled-provider and file-access failures require controlled local acceptance before claiming their live coverage.
